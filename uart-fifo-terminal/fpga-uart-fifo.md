# FPGA 外设的设计、时序与上板

目标是在目标时钟下完成“采样写入 FIFO → 更新状态和计数 → UART 读回”。终端和验证环境共用[串口与寄存器规格](README.md#串口和寄存器约定)。本页各步均待执行。

## 从计数器开始

1. 在独立的小工程中编写带复位和使能的计数器。用 XSim 自检复位值、连续使能和使能暂停，保存基线日志。先把步长由 1 改为 2，更新测试预期并复测、综合，比较两次计数序列和资源。集成进外设时恢复步长 1，用 FIFO 实际接受写入作为使能。
2. 加同步 FIFO。把“提出读写”和“接受读写”的信号分别引到波形，观察复位后第一次写、写到满、满时再写以及暂停后恢复。记下第一处与规格不符的时钟沿，再定位到指针、占用量或标志更新。[对应自检用例](fifo-verification.md)
3. 加 UART 收发与命令解析。可先用开源行回显示例观察一个字节怎样变成一行，再实现项目约定的命令。仿真中发 `id` 和未知命令，接着写入已知个数的样本，核对 `stat` 和 `cnt`。同时发起采样和状态查询时，检查返回的三个标志来自同一拍。[wbuart32 行回显示例](https://github.com/ZipCPU/wbuart32/blob/master/bench/verilog/linetest.v)

## 从综合报告走到实板

| 里程碑 | 动手内容 | 留下什么 |
| --- | --- | --- |
| 综合与实现 | 按目标板原理图确定时钟和引脚，用 XDC 约束实际输入时钟。跑综合、布局布线，检查时钟覆盖和未约束路径。 | 板卡与器件、目标频率、布局布线后的建立/保持最差余量、LUT/FF 使用量，以及一条关键路径的起点和终点。 |
| 首次串口查询 | 核对 ADV 和目标板两端电平、收发方向、公共地及波特率，下载 bitstream，按 `I` 查询。 | bitstream 的 build ID、终端回读和板卡版本。接线参考[终端实验](learn-freertos.md)。 |
| 故障复现 | 用片上逻辑分析仪（ILA）抓写请求、读握手、满空标志和计数，复现同一组暂停与恢复激励。 | 对齐的仿真与 ILA 波形。面向技术应用岗时，再写下触发条件、首次异常、修改和复测结果。 |

手边只有目标器件配置时，先完成仿真与实现报告，等拿到实板再做串口和 ILA 验收。Vivado 报告的字段可对照 [AMD 2025.1 时序报告指南](https://docs.amd.com/r/2025.1-English/ug906-vivado-design-analysis/Report-Timing-Summary)。
